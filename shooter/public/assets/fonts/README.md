# Bundled print faces

Locally served; no external font request is made by the game. The user's alphabet image is a visual reference, not an identified font file.

- Special Elite (distressed typewriter UI): [official source](https://github.com/google/fonts/tree/main/apache/specialelite), Apache 2.0; see `SpecialElite-LICENSE.txt`.
- IM Fell English SC (newspaper masthead and headings): [official source](https://github.com/google/fonts/tree/main/ofl/imfellenglishsc), SIL Open Font License; see `IMFellEnglishSC-OFL.txt`. Upstream filename `IMFeENsc28P.ttf`, renamed locally for clarity.

Downloaded from the official Google Fonts repository on 2026-10-25. Heading letter sizes vary subtly and deterministically; HUD numbers and input text remain stable.
